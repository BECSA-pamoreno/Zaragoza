Campos del nombre
1Campus
Fijo para todo el proyecto (BEP §3.3.3).
2Facility
Instalación / edificio (BEP §3.3.4).
3Zone / Volume
Zona o volumen del proyecto (BEP §3.3.5). Campo obligatorio — solo su significado cambia en paquetes PIGA/Tender.
⚠ En este código el primer carácter identifica el paquete (PIGA/Tender), no una zona física. Debe usarse de forma consistente y documentada.
4Levels / Location
Nivel o ubicación vertical (BEP §3.3.6).
5Information Type
Tipo de información del contenedor (BEP §3.3.7).
6Discipline
Disciplina / rol responsable (BEP §3.3.8).
7Document Type
⚠ La tabla de códigos depende de la disciplina elegida en el campo 6 (BEP §3.3.9).
⚠ El BEP no define una tabla de Document Type específica para esta disciplina. Usa código genérico o consulta al BIM Manager.
8Number
Secuencial de 2 dígitos (00–99) dentro del subgrupo de Document Type (BEP §3.3.10).
⚠ Debe ser numérico de 2 dígitos (00–99).

Recordatorios del BEP
  • La revisión y el status NO van en el nombre. Se gestionan aparte en el CDE y en el cajetín (S0–S7, D1–D4, A/B/CR + P01/C02…).
  • El número de plano en el cajetín debe coincidir exactamente con este nombre generado.
  • Ficheros no conformes con esta convención serán rechazados en el CDE (BEP §3.13.3).
  • Al subir una revisión, el nombre debe ser idéntico al de la versión anterior — cualquier variación crea un fichero duplicado en Autodesk Docs.
